# VoiceScribe — Installation Guide

This guide covers everything you need to install and run VoiceScribe on your system.

Choose your preferred setup method:
- 🤖 **[Method 1: Automatic Setup via CLI Agent](#method-1-automatic-setup-via-cli-agent-recommended)** *(Easiest — 1 prompt does everything)*
- 🛠️ **[Method 2: Manual Installation](#method-2-manual-installation-step-by-step)** *(Step-by-step for Windows, macOS, and Linux)*

**Time needed:** ~10–15 minutes (depending on your internet speed).

---

## 1. Prerequisites & Disk Space Breakdown

Here is the exact disk space required for each tool and component:

### A. System Tools
| Tool | Minimum version | Exact size (Linux) | Approx. size (Windows / macOS) | Why it's needed |
|---|---|---|---|---|
| **Node.js (with npm)** | **20.19+** (`node -v` / `npm -v`) | **~61 MB** | ~80–120 MB | Next.js 16 runtime (`npm` comes bundled with Node.js) |
| **FFmpeg** | Any recent version | **~51 MB** | ~100–180 MB | Audio denoise, merging, and studio mastering (runs server-side) |
| **Git** | Any recent version | **~34 MB** | ~150–280 MB | Clones the repo and pulls updates (`git pull`) |
| **Subtotal (Tools)** | | **~146 MB** | **~330–580 MB** | |

> *Note: If you prefer `pnpm` instead of `npm`, that works too (`pnpm@11` is supported).*

### B. Project Files & Dependencies
| Component | Path / Folder | Exact Size | Notes |
|---|---|---|---|
| **Source Code** | `voicescribe/` | **~2.5 MB** | Application code, icons, and configuration |
| **Git Metadata** | `.git/` | **~2.9 MB** | Local repository commit history |
| **Dependencies** | `node_modules/` | **~509 MB** | Next.js 16, React 19, Tailwind, FFmpeg bindings, etc. |
| **npm Download Cache** | `~/.npm/` | **~150–200 MB** | Local npm archive cache for fast re-installs |
| **Build Output** *(Optional)* | `.next/` | **~241 MB** | Generated by `npm run build` (not needed for dev mode) |

### Grand Total Disk Space

| Installation Type | Linux (Exact) | Windows / macOS (Approx.) |
|---|---|---|
| **Development Setup** (Tools + Code + `node_modules` + npm cache) | **~710–760 MB (~0.8 GB)** | **~900–1,200 MB (~1.0–1.2 GB)** |
| **Full Production Setup** (Dev setup + `.next/` build output) | **~950–1,000 MB (~1.0 GB)** | **~1,200–1,450 MB (~1.2–1.5 GB)** |
| **Recommended Free Space to keep handy** | **~1.5–2.0 GB** | **~1.5–2.0 GB** |

> Keep at least **~1.5–2 GB** of free disk space for temporary download buffers and build cache headroom.

## Method 1: Interactive Setup via CLI Agent (Recommended)

If you have a terminal AI agent (such as **Claude Code**, **Cursor CLI**, **Google Antigravity CLI**, **Codex**, or **GitHub Copilot CLI**), you can give it this structured prompt. 

The prompt instructs the agent to **first inspect your system**, report what tools are already installed vs. missing, wait for your confirmation, and only then proceed with the installation.

### The CLI Agent Prompt

Copy and paste this prompt into your CLI agent:

```text
Please help me set up the VoiceScribe project on my machine:

1. Pre-flight Check: Detect my operating system and check if Node.js (v20.19+), npm, Git, and FFmpeg are already installed (check their versions).
2. Report & Confirm: Show me a clear summary table of what is already installed vs. what is missing. Tell me what needs to be installed, and ask for my confirmation ("Would you like to proceed with the setup?") before running any install commands.
3. Installation (on my approval): Once I confirm ("yes", "proceed", "let's do it", etc.):
   - Install any missing system tools using the proper package manager (winget on Windows, Homebrew on macOS, or apt/dnf/pacman on Linux).
   - Clone the repository: https://github.com/Rohantelang01/voicescribe.git
   - Navigate into the 'voicescribe' folder and run 'npm install'.
4. Completion & Next Steps: Once everything is successfully installed, notify me with a message that installation is complete, and provide the exact command to start the development server ('npm run dev' or './start.sh') so I can test it at http://localhost:3000.
```

*(If you forked the repository, replace the URL with your fork).*

### How the Agent Workflow Works:

| Phase | What the Agent Does |
|---|---|
| **1. Inspection** | Runs non-destructive checks (`node -v`, `git --version`, `ffmpeg -version`) to see what you already have. |
| **2. Transparency** | Displays a clear summary of what's installed vs. missing, and pauses for your approval. |
| **3. Installation** | On your confirmation, installs missing tools, clones the repo, and runs `npm install`. |
| **4. Hand-off** | Sends you a completion message with the exact command to start the dev server and test the app. |

> **Next step after launch:** Open `http://localhost:3000`, click the **Keys** button in the header, and add your free Groq and Gemini API keys (see [Section 3](#3-add-api-keys-groq--gemini)).

## Method 2: Manual Installation (Step-by-Step)

Follow this section to install everything manually.

### Step 2.1: Install Node.js, FFmpeg, and Git

Select your operating system below:

#### 🪟 Windows 10 / 11 (Recommended)

**Option 1 — winget (Fastest & automated):**

Open **PowerShell as Administrator** and run:

```powershell
winget install -e --id OpenJS.NodeJS.LTS
winget install -e --id Git.Git
winget install -e --id Gyan.FFmpeg
```

*Or install all three in a single command:*
```powershell
winget install OpenJS.NodeJS.LTS Git.Git Gyan.FFmpeg
```

**Important:** Close and reopen PowerShell so your system PATH updates, then verify:
```powershell
node --version    # Should print v20.19+ or v22+
npm --version     # Should print 10.x or 11.x
git --version     # Should print git version
ffmpeg -version   # Should print ffmpeg version
```

> **PowerShell execution policy tip:** If PowerShell blocks running npm scripts with an execution error, run:
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

**Option 2 — Manual installers:**
* **Node.js:** Download the LTS Windows Installer (.msi) from [nodejs.org](https://nodejs.org).
* **Git:** Download the 64-bit installer from [git-scm.com](https://git-scm.com).
* **FFmpeg:** Download `ffmpeg-release-essentials.zip` from [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), extract it (e.g. to `C:\ffmpeg`), and add its `bin` folder to your Windows System PATH.

---

#### 🍏 macOS

Open Terminal and use **Homebrew**:

```bash
# If Homebrew is not installed:
# /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

brew install git node ffmpeg

# Verify installation
node --version
npm --version
ffmpeg -version
```

---

#### 🐧 Linux

Linux packages are straightforward. Run the commands for your distribution:

**Ubuntu / Debian / Linux Mint / Pop!_OS:**
```bash
sudo apt update && sudo apt install -y git ffmpeg curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs

# Verify
node --version && npm --version && ffmpeg -version
```

**Fedora / RHEL / CentOS:**
```bash
sudo dnf install -y git ffmpeg
curl -fsSL https://rpm.nodesource.com/setup_22.x | sudo -E bash -
sudo dnf install -y nodejs
node --version && npm --version && ffmpeg -version
```

**Arch / Manjaro / CachyOS:**
```bash
sudo pacman -Syu --noconfirm git ffmpeg nodejs npm
node --version && npm --version && ffmpeg -version
```

### Step 2.2: Download the Project

Clone the repository using Git:

```bash
git clone https://github.com/Rohantelang01/voicescribe.git
cd voicescribe
```

> **Alternative without Git:** You can also download the project ZIP from GitHub (**Code → Download ZIP**), extract the archive, and open a terminal inside the `voicescribe` folder.

---

### Step 2.3: Install Dependencies and Run

Run this command inside the project folder:

```bash
npm install
```

This installs all dependencies into `node_modules/` (takes ~1–3 minutes on first run).

#### Start the Development Server:

```bash
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.

* **Linux / macOS shortcut:** You can run `./start.sh` (run `chmod +x start.sh` once first) — it starts the server and opens your browser automatically.
* **Windows shortcut:** Run `npm run dev` directly in PowerShell or Git Bash.

#### Production Mode (Optional):

```bash
npm run build
npm start
```

| Command | Purpose |
|---|---|
| `npm run dev` | Development server with hot-reload (recommended for normal use) |
| `npm run build` | Compiles a production build |
| `npm start` | Serves the production build |
| `npm run lint` | Checks TypeScript and ESLint code standards |

*(Note: If you prefer `pnpm`, `pnpm install`, `pnpm dev`, `pnpm build`, and `pnpm start` work identically).*

## 3. Add API Keys (Groq + Gemini)

The app interface will open without keys, but transcription and TTS features require API keys. Both keys are **free**:

| Provider | Where to get it | Key Format | Used for |
|---|---|---|---|
| **Groq** | [console.groq.com/keys](https://console.groq.com/keys) — free signup → *Create API Key* | `gsk_…` | Whisper transcription & text transforms |
| **Gemini** | [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey) — *Get API Key* | `AIza…` | Voiceover Studio (TTS), transcription fallback |

### How to enter keys:
1. Open [http://localhost:3000](http://localhost:3000).
2. Click the **Keys** button in the top header.
3. Paste your Groq key and click **Save**.
4. For Gemini, click **Add Project** → paste key → **Save**.
5. *(Tip: Adding multiple Gemini project keys multiplies your daily free quota).*

> **Privacy:** Keys are stored securely in your browser's local storage (`localStorage`). They are never saved to disk or sent to any third-party server besides Groq and Google AI endpoints.

## 5. Troubleshooting

| Issue | Solution |
|---|---|
| `node: command not found` or older than 20.19 | Reinstall Node.js 22 LTS and restart your terminal. |
| `ffmpeg: command not found` | Reinstall FFmpeg and verify with `ffmpeg -version`. On Windows, ensure FFmpeg's `bin` folder is added to PATH. |
| PowerShell script execution blocked on Windows | Run `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` in PowerShell. |
| Port 3000 already in use | Run on an alternate port: `npm run dev -- -p 3001` → open `http://localhost:3001`. |
| Network error during `npm install` | Run `npm cache clean --force` and retry without VPN/proxy. |
| 429 / Rate Limit error on AI calls | Select a `*-lite` model for Gemini or `gpt-oss-20b` for Groq; see [`docs/MODELS.md`](docs/MODELS.md). |
| Data vanishes on refresh | Normal windows persist storage; private/incognito windows wipe `localStorage` on close. |
